# Background Image

The Background tab places an image — typically a seismic section — behind the cross section, registered to real coordinates.

1. **Upload** the image (*Upload Background Image*).
2. **Register** it: enter the geo-coordinates of the image's left, right, top, and bottom edges. A live zoom window helps you match features precisely, and the overlay frame can be dragged and resized.
3. **Crop** if only part of the image is relevant; **Reset** (or ESC) discards adjustments.

Once registered, the image's visibility and cropping are controlled from the Profile tab under **Components**, alongside the other scene elements. Delete the image from this tab when it is no longer wanted.
