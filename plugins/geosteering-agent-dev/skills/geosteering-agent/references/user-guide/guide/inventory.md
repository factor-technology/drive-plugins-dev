# Inventory

The Inventory tab lists every data object in the project and lets you inspect and download each one.

The left column lists the items:

- **Active Log** — the LWD gamma log as loaded.
- **Measured Trajectory** — the surveys.
- **Planned Trajectory** — the well plan, if uploaded.
- **Pilot Log** — one entry per pilot well.
- **Computed Interpretation (MPE)** — the current computed result.
- One entry per **manual interpretation**.

Select an item to see its contents in the center pane — tabular data and charts — with download controls on the right.

The **Export to Native Archive** link at the top of the list exports the entire project as a portable archive; see [Import and Export](./import-export.md).
