# Background Image

The Background tab places an image — typically a seismic section — behind the cross section, registered to real coordinates.

1. **Upload** the image (*Upload Background Image*).
2. **Register** it. In **Registration** mode, drag and resize the overlay frame, or type its edges: left and right in VS, top and bottom in TVDSS (negative down). A live zoom window helps you match features precisely.
3. **Crop** if only part of the image is relevant: switch to **Crop** mode and drag the frame around the part to show.

**Reset** returns the frame to a default inset — and, in Registration mode, clears the coordinates — and saves that; it is not an undo.

Once registered, the image's visibility, cropping, and opacity are controlled from the Profile tab under **Components**, alongside the other scene elements. Delete the image from this tab when it is no longer wanted.
